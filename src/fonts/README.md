# Fonts

Bundled so the game loads without any outside server (needed for offline play).

- **Orbitron** (`orbitron-latin.woff2`, variable weight 400-900) and **Rajdhani** (`rajdhani-*.woff2`, weights 300-700), latin character set only.
- Source: Google Fonts (fonts.gstatic.com), downloaded Oct 2026.
